

# Clean Street Project

This project is a **Clean Street Application** with a backend (Node.js) and a frontend (React).

## 📂 Project Structure
- `clean-street-backend/` → Backend (Node.js + Express + DB)
- `client/` → Frontend (React / Vite)

## 🚀 Setup & Run

### Backend
```sh
cd clean-street-backend
npm install
npm start        # Start backend server
node test.js     # Run this for test backend part


cd client

npm run dev      # for run frontend part
